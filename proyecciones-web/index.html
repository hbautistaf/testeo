Notas:
  • Las tablas de ISR utilizadas son las vigentes en el archivo fuente (SAT MX).
  • El SBC está topado a 25 veces el UMA diario.
  • El IMSS incluye: Especie Excedente, Prestaciones en Dinero, Pensionados y Beneficiarios, Invalidez y Vida, y CEAV.
  • El Fondo de Ahorro se calcula al tope máximo (1.3× UMA × 30.4 días) — tanto empleado como patrón.
  • El ISR mensual se aplica sobre el sueldo nominal + otros gravables. El ISR anual sobre el ingreso anual gravable.
  • El AFORE se estima con rendimiento del 7% anual.
  • Las proyecciones se guardan en el almacenamiento local del navegador.
